# Nguyễn Thị Anh Phương - Portfolio

Trang web portfolio cá nhân của Nguyễn Thị Anh Phương.

## Công nghệ sử dụng
- HTML5 / CSS3 / JavaScript
- Tailwind CSS
- Lucide Icons
- Google Fonts (Instrument Serif, Playfair Display, Inter)

## Hướng dẫn chạy thử nghiệm
1. Khởi chạy server nội bộ (PowerShell):
   ```powershell
   .\server.ps1
   ```
2. Truy cập trình duyệt tại địa chỉ: `http://localhost:5173`

Hoặc bạn có thể mở trực tiếp file `index.html` trên bất kỳ trình duyệt web nào.
